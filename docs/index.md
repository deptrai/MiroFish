## Project Overview

MiroFish is a swarm-intelligence prediction engine that converts uploaded documents into graph-grounded social simulations and report-driven analysis workflows.

## Project Structure

### Frontend

- **Type:** Web app
- **Location:** `frontend/`
- **Stack:** Vue 3, Vue Router, Vue I18n, Axios, D3, Vite
- **Entry:** `frontend/src/main.js`

### Backend

- **Type:** API and orchestration
- **Location:** `backend/`
- **Stack:** Flask, Pydantic, OpenAI SDK-compatible LLM client, Zep Cloud, camel-oasis
- **Entry:** `backend/run.py`
